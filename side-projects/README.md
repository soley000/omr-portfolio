# 🌱 Side Projects

Cette section contient des projets personnels réalisés dans un objectif d’apprentissage et d’exploration technique.

Les side projects me permettent de :

- expérimenter différents modèles
- explorer des outils de data science
- construire des pipelines de traitement de données

Contrairement aux projets industriels, ces projets peuvent inclure :

- du code complet
- des datasets publics
- des expérimentations personnelles

## Projets

### Object Detection – YOLO vs SSD
Projet de détection d’objets dans des images avec comparaison de deux modèles populaires de computer vision.

Objectifs :

- comprendre le fonctionnement des modèles
- tester leurs performances
- construire une petite application de démonstration.
