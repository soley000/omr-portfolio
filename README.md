## 🚀 Projets industriels

Les projets industriels présentés ici décrivent **la méthodologie, l'architecture et les résultats**, mais **aucun code interne ni donnée confidentielle n'est exposé**.

### 1️⃣ [Vision & LLM Evaluation Framework for Driving Scenarios](industrial-projects/01_Coaching_Evaluation/)
Pipeline d'évaluation automatisée pour détecter les incohérences et hallucinations dans les descriptions générées par un système d'analyse interne de scènes de conduite.

### 2️⃣ [Benchmarking Vision Models](industrial-projects/02_Cosmos_Model_Evaluation/)
Analyse comparative de modèles vision-langage (Cosmos Reason1 & Reason2) appliqués aux scénarios de conduite — métriques qualitatives et tableau de synthèse.

### 3️⃣ [EV Charging Data Engineering for Grid Regulation](industrial-projects/03_EV_Data_Engineering/)
Reconstruction, nettoyage et agrégation de données télémétriques de véhicules électriques pour des analyses énergétiques stratégiques ⚡.

### 4️⃣ [Industrial Data Automation & Standardization](industrial-projects/04_Industrial_Data_Automation/)
Optimisation et automatisation de process Excel/VBA pour ingestion massive de données multi-pays 🗃️.

## 🌱 Side Projects

Les side projects sont des explorations personnelles avec code complet, datasets publics et résultats reproductibles.

### 🔍 [Détection d'Objets — YOLOv8 · DETR · OWL-ViT](side-projects/object-detection/)
Comparaison de trois paradigmes de détection d'objets : CNN one-stage, Vision Transformer et Open-Vocabulary. Application Streamlit interactive avec mode comparaison côte à côte.

Pipeline ML complet sur le dataset Kaggle House Prices : EDA, feature engineering, comparaison de modèles (Random Forest, Gradient Boosting, Régression Linéaire), analyse des biais, application Streamlit.

![](https://raw.githubusercontent.com/soley000/omr-portfolio/main/assets/images/House_ml_project_Prediction_page.png)
